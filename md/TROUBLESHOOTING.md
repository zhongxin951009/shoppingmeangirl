# 故障排除指南

## 问题：页面卡住，控制台显示错误

### 错误信息
```
script.js:517 Uncaught TypeError: Cannot read properties of null (reading 'style')
```

### 解决方案

我已经修复了这个问题。请尝试以下步骤：

#### 方案1：使用简化版（推荐）
打开 `front/simple.html` - 这是一个不依赖外部库的简化版本，功能完整。

#### 方案2：使用调试版
打开 `front/debug.html` - 这个版本会显示详细的调试信息，帮助定位问题。

#### 方案3：清除缓存后重新加载
1. 按 `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac) 强制刷新
2. 或者打开开发者工具，右键刷新按钮，选择"清空缓存并硬性重新加载"

#### 方案4：检查图片
确保 `mean-girls.jpg` 文件：
- 在 `front` 文件夹中
- 是真实的图片文件（不是文本文件）
- 文件名完全匹配（区分大小写）

## 常见问题

### Q1: 图片不显示
**检查项：**
- 文件路径是否正确
- 文件名是否匹配（区分大小写）
- 浏览器控制台是否有 404 错误

**解决方法：**
```bash
# 在 front 文件夹中检查文件
ls -la mean-girls.jpg
```

### Q2: 星星动画不显示
**原因：** 可能是浏览器不支持某些 CSS 特性

**解决方法：**
- 使用最新版 Chrome、Firefox 或 Safari
- 检查浏览器控制台是否有 CSS 错误

### Q3: 点击卡片没反应
**检查项：**
- 打开浏览器控制台查看是否有 JavaScript 错误
- 确认 script.js 文件已正确加载

**解决方法：**
- 使用 simple.html 测试基本功能
- 检查网络标签页，确认所有资源已加载

### Q4: 品牌部分不缩小
**原因：** 动画触发条件未满足

**解决方法：**
- 将鼠标移动到"Hey Gal"标题区域
- 或者向下滚动页面
- 或者点击任意卡片区域

## 开发者工具使用

### 打开控制台
- Windows/Linux: `F12` 或 `Ctrl+Shift+I`
- Mac: `Cmd+Option+I`

### 查看错误
1. 打开控制台
2. 切换到 "Console" 标签
3. 查看红色错误信息

### 查看网络请求
1. 打开控制台
2. 切换到 "Network" 标签
3. 刷新页面
4. 查看是否有失败的请求（红色）
