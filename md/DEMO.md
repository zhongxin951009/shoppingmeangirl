## 🎨 动画效果

### 霓虹灯标题
```
Your Shopping Mean Girl
↓
发光强度变化：20px → 30px → 20px
颜色：#ff1493 → #ff69b4 → #ff1493
持续时间：2秒循环
```

### 品牌缩放
```
初始：height: 50vh
↓ (0.5秒过渡)
缩小：height: 25vh
```

### 星星动画
```
✨ 位置：(x, y)
↓ (1.5秒)
✨ 向上飘动：translateY(-30px)
✨ 旋转：rotate(360deg)
✨ 缩放：scale(0 → 1.2 → 0)
✨ 透明度：0 → 1 → 0
```

### 卡片悬停
```
普通状态：
- 背景：rgba(255, 255, 255, 0.1)
- 边框：rgba(255, 255, 255, 0.2)

悬停状态：
- 背景：rgba(255, 105, 180, 0.2)
- 边框：#ff69b4
- 位移：translateX(5px)
- 阴影：0 5px 20px rgba(255, 105, 180, 0.3)
- 星星：显示并动画
```

## 🎯 交互流程

### 用户操作流程
```
1. 打开页面
   ↓
2. 看到品牌形象（占 1/2 屏幕）
   ↓
3. 鼠标移到下方或滚动
   ↓
4. 品牌缩小，显示标题和卡片
   ↓
5. 悬停卡片，看到星星动画
   ↓
6. 点击选择消费金额
   ↓
7. 点击选择购买驱动力
   ↓
8. "下一步"按钮变为可用
   ↓
9. 点击进入下一页
```
