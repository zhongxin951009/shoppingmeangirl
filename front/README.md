# 前端文件说明

## 📁 文件列表

### HTML 文件

1. **index.html** - 完整版应用
   - 包含所有功能
   - 需要配置 Supabase 和智谱 API
   - 适合生产环境

2. **standalone.html** ⭐ **推荐使用**
   - 独立运行版本
   - 不需要任何配置
   - 功能完整，适合测试和演示
   - **如果遇到问题，请先打开这个文件**

3. **simple.html** - 简化版
   - 最小化代码
   - 使用内联事件
   - 适合学习和调试

4. **debug.html** - 调试版
   - 显示实时调试信息
   - 帮助定位问题
   - 适合开发者

5. **test.html** - 效果演示
   - 展示设计效果
   - 测试动画和样式
   - 不包含完整功能

### 其他文件

- **style.css** - 样式文件（所有 HTML 共用）
- **script.js** - 完整版 JavaScript（仅 index.html 使用）
- **mean-girls.jpg** - 品牌图片
- **IMAGE_SETUP.md** - 图片设置说明

## 🔧 故障排除

### 问题：页面卡住或报错

**解决方案：**
1. 打开 `standalone.html`（最稳定）
2. 或打开 `debug.html`（查看错误信息）
3. 清除浏览器缓存后刷新

### 问题：图片不显示

**检查：**
- 文件名是否为 `mean-girls.jpg`
- 文件是否在 `front` 文件夹中
- 浏览器控制台是否有 404 错误

**解决：**
- 页面会自动显示占位符
- 不影响其他功能使用

### 问题：星星动画不显示

**原因：**
- 浏览器版本过旧
- CSS 动画被禁用

**解决：**
- 使用最新版 Chrome/Firefox/Safari
- 检查浏览器设置
